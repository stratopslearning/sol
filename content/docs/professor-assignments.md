# Assignments

Assignments is the unified place for course work: **quizzes**, **lessons**, **discussions**, and **interactives**.

## Types

| Type | What students do | Gradebook |
| --- | --- | --- |
| Quiz | Attempt questions | Numeric score |
| Lesson | Read + flashcards | Completion |
| Discussion | Socratic chat | Completion |
| Interactive | Fill blanks, drag words, hotspots, accordion, or imported H5P | Completion |

## Creating work

- **New quiz / discussion / interactive** from Assignments, or publish from **Authoring**.
- **Import H5P** uploads a `.h5p` file for students to complete (status only in v1).

## Release

Authoring still uses **publish (inactive) → release**. Dashboard-created interactives can be released from the interactive edit page.
